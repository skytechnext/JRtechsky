Integration principles

Native first

Use built-ins before code

Payments, bank sync, email, e-commerce and MyInvois ship as Odoo providers/localisations. Configure these before building anything custom.

Event-driven

Webhooks over polling

WhatsApp and IoT push events to Odoo via webhooks/automated actions, avoiding brittle polling and keeping data fresh.

Secured

Scoped API access

External services authenticate with dedicated API users and the least-privilege roles defined on Security & Compliance.

So what for the Odoo build: the only must-have at go-live integrations are MyInvois, at least one MY payment method (FPX), bank reconciliation and email. WhatsApp and IoT/telemetry are sequenced into later phases on the roadmap, in step with the AI use-cases that depend on them in the AI catalog.
