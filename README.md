# JR Tech Solution — Static Site Export

A static, WordPress-free recreation of **https://jrtech.com.my/** (JR Tech Solution —
Commercial Kitchen Solution Provider), crawled and exported to plain HTML + assets.

## Why

The live site is a WordPress install that currently prints PHP warnings on every page
(duplicate `define()`s in `wp-config.php` and a WPBakery/`js_composer` plugin that is
incompatible with the server's PHP 8 version). This export captures the rendered site as
self-contained static files that open directly in a browser — no PHP, database, or
WordPress required.

## Contents

| Path | Description |
|------|-------------|
| `jrtech.com.my/` | The exported static site. Open `jrtech.com.my/index.html` to browse. |
| `jrtech.com.my/wp-content/uploads/` | All images and media used by the site. |
| `jrtech.com.my/wp-content/...` | Theme/plugin CSS & JS needed for layout. |

Internal links were rewritten for offline browsing, and the PHP `Warning:` lines that the
broken WordPress prepended to every page were stripped during export.

> **Status:** generated by an automated crawl. See the commit history for the export run.
