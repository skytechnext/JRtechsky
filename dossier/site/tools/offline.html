Cache the entire dossier to this device for reading without internet — on a flight, at a site visit, anywhere. Once cached, every page, diagram, floorplan and PDF opens instantly offline.

It also happens automatically. Every page you visit while online is cached in the background (and silently refreshed when content updates). The button simply fetches everything at once so nothing is missing mid-flight.

2 · Install as an app

iPhone / iPad

Open this site in Safari → Share button → Add to Home Screen. The dossier opens full-screen like an app and reads offline once cached.

Android

Open in Chrome → menu ⋮ → Add to Home screen (or "Install app" when offered).

Laptop

Chrome/Edge → install icon in the address bar (or menu → Cast, save & share → Install). A standalone dossier window, offline-ready.
