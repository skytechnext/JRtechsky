Critical path: the engagement's longest dependent chain runs solution design → core data migration → SST/MyInvois accounting build → core UAT → operations UAT → final cutover. These tasks carry the least float — any slip moves go-live one-for-one. They map directly to the red bars in the Gantt and the top entries of the Risk Register & RACI. Training runs in parallel off the accounting build, so it does not extend the path.

Resource loading by phase

Effort is not flat across the plan. This shows planned person-days by role across the five phases — the basis of the staffing profile and the resource line in the ROI / TCO model. Build effort peaks in Phase 1–2; super-user load rises into UAT and training.

So what for the build: the developer/consultant peak in Phases 1–2 sets when TechNext capacity must be ring-fenced, while the super-user ramp in Phase 1 UAT and Phase 4 training is the JR-Tech commitment that protects adoption — the leading indicator on the KPIs & Benefits page.
