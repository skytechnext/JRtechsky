S3 AI Engine — generate the 4 packsSLA · 72 h from meeting Owner: SKY / TechNext operator
Templates: AGL samples

Run four sub-skills in order — each mirrors an AGL sample document (Blueprint · Operations · Financials · Handover). Numbers must reconcile across all four.

You are JR-Tech's kitchen-planning engine. Using the attached 4 inputs and following the
structure of our AGL sample documents exactly (same sheets, same tables, same plan types):

PACK A — Kitchen Blueprint: zoned floorplan with one-way food-safety flow; costed
equipment schedule with per-item kW, electrical / water / drainage points; electrical +
drainage point schedules and load summary with supply recommendation; ventilation and
LPG design; MBPP / BOMBA compliance checklist.
PACK B — Operations: menu engineering (dish costing + stars matrix); crew org and
station duties sized to the seat count; SOP library; HACCP CCPs + Malaysian requirements
(LPM food-handler, TY2); daily / weekly / monthly schedules; opening-crew training plan.
PACK C — Financials: normal-day output model (covers x check, throughput vs the
constraint station); monthly P&L with electricity derived from the equipment loads;
12-month ramp + break-even, 3 scenarios; savings vs a typical kitchen (electricity +
labour) with a 5-year view; sensitivity + assumptions register.
PACK D — JR-Tech Handover: phased delivery/installation plan + timeline gantt;
maintenance programme with SLAs; JR-Tech account revenue (one-off + recurring);
quotation with milestones; proposal binder contents; Day-0 signing automation map.

Rules: one reconciled number set across all packs; every figure marked as modelled;
Malaysian context (RM, SST, TNB tariff, MBPP). Ask before assuming anything material.
Inputs: [ATTACH THE 4 CAPTURE DOCS]
Done when
  • 4 packs drafted in the client's folder
  • Cross-pack numbers reconcile (investment, recurring, covers, kW)
